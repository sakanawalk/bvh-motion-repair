# 実装の由来と処理順

`engine.py` は制作工程のBVH補修ステージAから抽出しています。
BVHパーサー・順運動学・クォータニオン補間・動的計画法による前腕ブランチ選択・二関節IKを含みます。
旧スクリプトの曲名・時刻指定・個人PCのパス・制作結果のコメントは除去しています。
AI支援で作成・整理されたコードであり 新規性・特許非侵害・万能な修復能力を主張するものではありません。

1. 入力の構造・fps・骨名・軸・スケールを検査し 原本のハッシュと診断候補を記録。
2. 全身の停止区間・指定した単発異常を補間。上腕の往復する折り返しを先に補正。
3. 手首との相対回転も評価し 前腕の通常/180度ブランチを動的計画法で選択。
4. 前腕・手の停止を親相対で補間。残ったねじれや手首関係角の異常を補修。
5. 短い往復スパイクを補間し クォータニオンを平滑化。手は前腕相対で処理。
6. 推定した手の甲側の過大屈曲を補間。
7. 低く遅い足先を接地候補とし 二関節IKで補正。膝の追加伸展を制限し 膝方向を平滑化。
8. Euler角を連続な枝で出力し 再読込の順運動学誤差を確認。

公開化で追加した主な変更:

- 入出力・設定の引数化と新規出力ディレクトリの必須化。
- 曲固有の骨盤スナップ・手動補間を空の設定へ移動。
- 末尾まで続く全身停止を補間しない（終端外参照を回避）。
- 接地候補ゼロの場合は平均値をnullとし 手の屈曲サンプルがない場合は甲側推定を省略。
- assert依存の検証を明示的な例外へ変換。
- 外部画像ライブラリと固定フォントを用いた制作プレビューを自己完結HTMLへ置換。

既知の限界: 軸ねじれの全身再配分は未実装。親の大回転を折り返しと扱うヒューリスティックには誤判定があります。
停止区間は意図的な静止と区別できない場合があります。速度の上限を人体の普遍的な法則とは扱っていません。
