# モーション修正ツール Windows版 0.2.0

Pythonのインストールやコマンド入力をせず BVHの飛び・ねじれを補修できる実験版の画面付きアプリです。

## 普段使う人へ

1. 配布ZIPを「すべて展開」します。
2. 「モーション修正ツール.exe」をダブルクリックします。
3. 「BVHを選ぶ」または「お試しデータを使う」でモーションを選びます。
4. 保存先と書き出し形式を確認して「修正する」を押します。
5. 完了後に「修正前後を比較する」で確認します。

元ファイルは上書きしません。実行ごとに別の結果フォルダを作ります。
採用する修正候補は `repaired.bvh` です。詳しい操作は [使い方](guide.html) を参照してください。

対応はWindows 64bitと 約120fps / cm単位 / Y-up / 指定の人型骨格のBVHです。
FBX・VMD・30/60fps・任意骨格への変換には対応しません。
自動修正は候補の作成です。振付の意図やキャラクター適用後の見た目は目視で確認してください。

## 開発・保守する人へ

このフォルダはソースコードです。Python環境がある場合は以下でも起動できます。

```console
python -m pip install .
python launch_desktop.py
python -m unittest discover -s tests -v
```

コア処理は0.1.0と同一です。0.2.0では日本語GUI・非同期実行・日本語比較画面・進捗表示・お試しデータを追加しました。
仕様は [プロファイル](docs/PROFILE.md) と [アルゴリズム](docs/ALGORITHM.md) を参照してください。
